# 스크린샷 촬영 목록

이 폴더에 아래 **파일 이름 그대로** 사진(PNG)을 넣으면, 요구사항 분석서를 다시 만들 때 "10. 실행 화면" 장에 자동으로 들어간다.
없는 파일은 건너뛰므로 찍은 것만 넣어도 된다. 촬영은 `Win + Shift + S`(캡처 도구)로 창만 잘라 저장하면 편하다.

| 파일 이름 | 찍을 화면 | 요구사항 |
| --- | --- | --- |
| 01_서버_콘솔.png | 서버 콘솔: 포트, TLS 지문, MariaDB 연결, 가입 승인 설정 | SV-01, SC-01 |
| 02_로그인.png | 로그인 화면 (서버 설정을 펼친 상태) | AU-02, SC-01 |
| 03_지문_확인.png | 처음 접속할 때 뜨는 서버 인증서 지문 확인 창 | SC-01 |
| 04_회원가입.png | 회원가입 화면 | AU-01 |
| 05_메인_창.png | 메인 창 (동료·채팅방 목록, 상태 표시) | CH-03, RM-01, CL-04 |
| 06_채팅방_대화.png | 채팅방 대화 (답장·공감·읽음 숫자가 보이게) | CH-01, CH-06~10 |
| 07_1대1_대화.png | 1:1 대화창 | CH-02 |
| 08_파일_전송.png | 파일 전송 진행률과 사진 미리보기 | FT-01~04 |
| 09_프로필_카드.png | 프로필 카드 (사진·배경·상태 메시지) | CL-05 |
| 10_친구_추가.png | 친구 추가 창 (검색 결과가 보이게) | CL-06 |
| 11_관리자_회원.png | 관리자 창 '회원' 탭 | AD-02, AD-03, AD-07 |
| 12_관리자_감사로그.png | 관리자 창 '감사 로그' 탭 | AD-06 |
| 13_관리자_통계.png | 관리자 창 '통계' 탭 | AD-09 |
| 14_다른_포트_접속.png | 서버를 다른 포트(예: 9100)로 띄우고 접속한 화면 (서버 콘솔과 로그인 창이 함께) | SV-01 |

주의: 화면에 실제 DB 비밀번호(appsettings.json)나 개인 정보가 보이지 않게 찍는다.
