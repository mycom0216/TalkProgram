# 사내톡 시연 시나리오 (영상 약 8~10분)

시연 영상은 이 순서대로 찍으면 요구사항 분석서의 주요 기능과 보안·운영 항목을 빠짐없이 보여 줄 수 있다. 괄호 안은 요구사항 ID다.

## 촬영 전 준비

| 준비 | 방법 |
| --- | --- |
| DB·서버 | MariaDB 실행 확인 → 서버 실행. 서버 콘솔에 `서버 시작: 0.0.0.0:9000 (TLS 암호화)`가 보이면 된다 |
| 계정 | 일반 사용자 2개(예: A0001, A0002)와 관리자 1개. 첫 관리자는 서버 콘솔에서 `/grant 사원번호` |
| 클라이언트 2개 | Visual Studio에서 ChatApp.Client 오른쪽 클릭 → 디버그 → 새 인스턴스 시작, 또는 다른 PC 한 대 |
| 두 번째 포트 | 서버를 하나 더 `ChatApp.Server.exe 9100`으로 실행 (포트는 첫 번째 실행 인자) |
| 화면 정리 | 바탕화면·알림 창·이메일 같은 개인 정보 가리기, Windows 방해 금지 모드 켜기 |
| 녹화 도구 | Windows 기본: `Win + Alt + R`(Xbox Game Bar) / 화면 전체와 소리를 모두 담으려면 OBS Studio |
| 준비물 | 보낼 사진 1장, 작은 문서 파일 1개, 큰 파일(수백 MB) 1개 |

## 촬영 팁
- 한 장면씩 따로 찍어 이어 붙이면 실수해도 그 장면만 다시 찍을 수 있다.
- 클라이언트 두 개를 화면 좌우로 나란히 놓으면 보낸 메시지가 상대 화면에 나타나는 것이 한눈에 보인다.
- 비밀번호 입력 장면은 시연용 임시 계정을 쓰고, 실제 DB 비밀번호가 보이는 파일(appsettings.json)은 화면에 띄우지 않는다.
- 스크린샷은 `docs/screenshots`에 정해진 파일 이름으로 넣는다(촬영목록.md 참고).
